# Nova Tech Solutions: Company Website

A multi-page company website built with Python and Django.

## Features
- Home, About and Contact pages
- Service pages loaded from the database, each with its own detail page
- Contact form that saves visitor messages to the database
- Customized Django admin panel with search, filters and read/unread tracking

## Built With
- Python
- Django
- HTML and CSS

## How to Run
1. Install Django: `pip install -r requirements.txt`
2. Set up the database: `python manage.py migrate`
3. Create an admin user: `python manage.py createsuperuser`
4. Start the server: `python manage.py runserver`
5. Open http://127.0.0.1:8000 in your browser
